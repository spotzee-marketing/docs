Spotzee ships three first-party SDKs for JavaScript, iOS and Android. Use the same external ID when you identify a contact on multiple surfaces so their activity can join the same record.

## Pick an SDK

| SDK | Distribution | Min target | Notes |
|---|---|---|---|
| JavaScript | npm / yarn / pnpm | Modern browsers and Node | Two client classes plus a typed client generated from the OpenAPI spec |
| iOS | Swift Package Manager + CocoaPods | iOS 13+ | APNs registration, in-app modals, Universal Links |
| Android | JitPack | Android SDK 23+ (Android 6.0 Marshmallow) | FCM registration, in-app dialogs, App Links |

## What every SDK does

- **Identifies contacts.** Mobile SDKs retain their local identity. The JavaScript `BrowserClient` creates an anonymous ID in memory for each instance; calling `identify` sends it with your external ID.
- **Tracks events.** A single `track` call flows into journeys, segments, and campaign triggers.
- **Registers devices.** The SDKs can send device details and mobile push tokens for the relevant channel.
- **Renders in-app notifications.** Banner, alert, and HTML content types. iOS and Android render natively; the JavaScript SDK fetches and lets you render however you want.
- **Authenticates with publishable keys** (`pk_…`). These are safe to ship in client builds. Read [Manage API keys](/guides/manage-api-keys) for the key model.
- **Pins an API version.** SDK requests use the version set by the installed release.

## Pick the right surface

| Use case | Reach for |
|---|---|
| Browser tracking and simple Node integrations | JavaScript client (`Client` / `BrowserClient` / `Spotzee`) |
| Server-side, agentic, or full-coverage Node integrations | JavaScript [typed client](/guides/sdks/javascript/typed-client) (`@spotzee/js-sdk/generated`) |
| Native iOS app | [iOS SDK](/guides/sdks/ios/install) |
| Native Android app | [Android SDK](/guides/sdks/android/install) |
| Cross-platform mobile apps or server-side languages without an SDK | Call the [Main API](/main-api/introduction) directly with a publishable or secret key |
