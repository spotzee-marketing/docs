The email syntax validator checks an address's format and returns whether it passes the format check. It does not contact the mailbox provider or confirm that the domain accepts mail. A valid result is therefore a reason to continue verification, not a delivery guarantee.

<Info>
Run a one-off check at [spotzee.com/tools/email-syntax-validator](https://spotzee.com/tools/email-syntax-validator/). The web form sends the address for validation. Extended API calls use your Spotzee credit balance; see [pricing](https://spotzee.com/pricing/) for current rates.
</Info>

## Check an address

<Steps>
  <Step title="Enter the address">
    Paste one email address into the tool or send it to the Extended API's email syntax validator endpoint.
  </Step>
  <Step title="Read the verdict">
    Use an invalid result to prompt correction or remove a malformed address from an import. A valid result only confirms the format check passed.
  </Step>
  <Step title="Check delivery separately">
    If you need to know whether the domain receives mail, use [MX lookup](/guides/tools/dns-auth/mx-lookup). For a broader address assessment, use [email validation](/guides/tools/email-validation/email-validation).
  </Step>
</Steps>

A misspelt but correctly formed domain can pass syntax validation. Check addresses such as `name@gmial.com` with a domain or provider lookup before relying on them.
