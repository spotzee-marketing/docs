Email address validation checks one address and returns a status with detail fields. Spotzee rejects malformed input before requesting a broader validation result. A `valid` result is a point-in-time assessment, not proof that future messages will reach an inbox.

<Info>
Run a one-off check at [spotzee.com/tools/email-validation](https://spotzee.com/tools/email-validation/). Extended API calls use your Spotzee credit balance; see [pricing](https://spotzee.com/pricing/) for current rates.
</Info>

## Check an address

<Steps>
  <Step title="Enter the email address">
    Use the web form or submit the `email` field to `POST /generic/email/email-validation`.
  </Step>
  <Step title="Review the status">
    Read `result` and `expanded_result` together. Spotzee maps an `ok` result from the validation service to `valid` in its response.
  </Step>
  <Step title="Review address flags">
    The response also includes `free` and `role` flags and, when available, a `didyoumean` suggestion. A suggested correction still needs confirmation from the address owner.
  </Step>
</Steps>

A syntax-only check cannot establish whether an address receives mail. Use the [email syntax validator](/guides/tools/email-validation/email-syntax-validator) when you need only to reject malformed input.
