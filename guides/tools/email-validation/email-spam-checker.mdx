The email spam checker analyses a message you send to a generated test address. It scores nine groups: SPF, DKIM, ARC, DMARC, sending domain, sending IP, message body, subject line and links. The score describes checks on the captured message. It does not predict where every mailbox provider will place a campaign.

<Info>
Use the [web tool](https://spotzee.com/tools/email-spam-checker/) for one message. The Extended API also exposes the address and results endpoints. Generating an address uses your Spotzee credit balance; see [pricing](https://spotzee.com/pricing/) for current rates.
</Info>

## Run a test through the API

<Steps>
  <Step title="Generate a test address">
    Call `GET /generic/email/email-tester`. Read `data.test_email` and `data.uniqueCode` from the response.
  </Step>
  <Step title="Send the message">
    Send your draft to `test_email` using the same sending configuration you intend to check. Use a test message without sensitive customer data.
  </Step>
  <Step title="Read the result">
    Call `GET /generic/email/email-tester-results/{uniqueCode}`. If the response says to check back later, wait and poll again with a deadline suitable for your integration.
  </Step>
  <Step title="Investigate the score">
    When analysis is ready, compare `obtainedScore` with `totalCritereaScore` and inspect the nine result groups. Fix concrete authentication, reputation, body or link findings, then send another test message.
  </Step>
</Steps>

The total score is 400 points. A high score is useful evidence about the measured signals, but it is not an inbox-placement guarantee. Recipient engagement and each mailbox provider's own filters are outside this result.
