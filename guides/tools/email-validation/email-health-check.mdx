Use the email health check to inspect a domain's public mail and authentication records. It reports an overall score, the results of nine check groups, and `dataCompleteness` so you can see when a check was missing. The score is a configuration review, not an inbox-placement test.

<Info>
Enter a domain or full email address at [spotzee.com/tools/email-health-check](https://spotzee.com/tools/email-health-check/). The service extracts the domain from an email address.
</Info>

## Check a domain

<Steps>
  <Step title="Submit a domain">
    Enter a domain or email address. The API also accepts `dkim_test_type`: `quick` or `full`.
  </Step>
  <Step title="Check data completeness">
    Read `dataCompleteness.percentage`, `missingChecks`, and `failureReason` before interpreting the score. A technical failure can leave some groups unmeasured.
  </Step>
  <Step title="Inspect each result group">
    Read the MX, SPF, DMARC, DKIM, BIMI, MTA-STS, TLS-RPT, CAA, and domain results. Each group reports its own score and details where available.
  </Step>
  <Step title="Verify a finding before changing DNS">
    Confirm the relevant record and your provider's configuration. The result cannot confirm that a real message passed authentication or reached an inbox.
  </Step>
</Steps>

## How scoring works

The service adds group scores and divides by a fixed 280-point maximum. The configured maxima are MX 30, SPF 60, DMARC 60, DKIM 60, BIMI 0, MTA-STS 10, TLS-RPT 5, CAA 5, and domain 50. `dataCompleteness` is separate from the score: missing groups contribute zero rather than reducing the maximum.

<Warning>
DKIM results have two known limits. Although the API accepts `full`, the check uses the same selector set as `quick`. When that set finds no DKIM selector, the current scoring logic awards full DKIM points. Do not treat a high DKIM or overall score as proof that signing is configured. Check the selector from an actual sent message and verify its DNS record separately.
</Warning>

The check reads public records and domain signals. It does not send a probe message, measure open rates, or establish delivery. For a focused SPF record read, see [SPF lookup](/guides/tools/dns-auth/spf-lookup); for a focused DMARC record read, see [DMARC lookup](/guides/tools/dns-auth/dmarc-lookup).

The same check is available through the Spotzee Extended API at `POST /generic/email/email-health-check`. API calls use your credit balance; see [pricing](https://spotzee.com/pricing/) for the current rate.
