Use the phone number validator to check a number's format and obtain a normalised international number when validation succeeds. A valid result confirms the number's format; it does not confirm that the line is active, reachable, or able to receive SMS.

<Info>
Try a number at [spotzee.com/tools/phone-validator](https://spotzee.com/tools/phone-validator/).
</Info>

## Check a number

<Steps>
  <Step title="Enter the number with its country code">
    Include the leading `+` and international dialling code, such as `+61` for Australia. The service does not set a default country for local numbers.
  </Step>
  <Step title="Read the result">
    Check `isValid`. For a valid number, the response can include `phoneNumber` in E.164 format, `countryCode`, `countryIso2`, and `countryIso3`.
  </Step>
  <Step title="Use the normalised value">
    If you store or submit the number elsewhere, use the returned `phoneNumber` rather than assuming the original formatting is accepted.
  </Step>
</Steps>

E.164 uses `+` followed by a country code and national number, without spaces or punctuation. Country codes can identify a numbering region rather than a person's location. The validator delegates format checks to its phone-number parser, so a rejected number should be checked against the relevant numbering plan before treating it as unreachable.
