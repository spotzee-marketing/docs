The Sendmux integration shows your account's email activity inside the Spotzee **Email Proxy** Tool. Connect with a Sendmux API key to view delivery metrics, provider status, billing balance, and delivery logs.

<Info>
The Spotzee view makes read requests to Sendmux. Provider configuration, routing rules, quotas and sending domains are managed in Sendmux. The `smx_root_` credential is a root key, so store and rotate it with the care you give other account credentials.
</Info>

## What you can see in Spotzee

Once connected, the **Email Proxy** Tool inside your project has two tabs:

- **Overview**: send activity for the last 24 hours, 7 days, or 30 days; provider counts; billing balance; and 30-day spend.
- **Logs**: per-message delivery logs with status, provider, and text filters. See [Sendmux delivery logs](/guides/tools/sendmux/logs).

What you can do **only on Sendmux.ai** (not in Spotzee):

- Add or remove SMTP, Gmail, or Microsoft 365 providers.
- Configure provider quotas, routing rules, and traffic distribution.
- Manage sending domains, tracking domains, and DKIM.
- Run test sends, import providers via CSV, and configure groups.

For all of those, follow the link from the Spotzee Tool to your Sendmux dashboard.

## Before you connect

You'll need:

- A **Sendmux account** at [sendmux.ai](https://sendmux.ai).
- A **Sendmux root API key** that starts with `smx_root_`. Generate one in the Sendmux dashboard; Spotzee uses it for read requests.
- The Spotzee project `admin` role.

## Connect Sendmux

<Steps>
<Step title="Open the Email Proxy Tool">
Inside the project, open **Tools** and pick **Email Proxy (Sendmux.ai)**. If no API key is configured, you'll land on a setup screen.
</Step>

<Step title="Paste your Sendmux API key">
Paste the API key that starts with `smx_root_` into the field and submit.
</Step>

<Step title="Validate">
Spotzee validates the key against Sendmux. On success, the Tool refreshes and the Overview tab populates with your account data.
</Step>
</Steps>

If validation fails, the key was rejected. Common causes: wrong key copied (must start with `smx_root_`), key revoked in the Sendmux dashboard, or insufficient permissions on the key. Generate a fresh key and try again.

## What the Overview tab shows

| Section | What you see |
|---|---|
| **Email metrics** | Sent, failed, total, rejected, and pending counts over the last 24 hours, 7 days, or 30 days. Sent and failed cards include period-over-period change indicators. |
| **Provider stats** | Active and total provider counts, provider types, and a notice when providers are in an error state. |
| **Billing balance** | Your Sendmux account's current credit balance. |
| **Billing summary** | Credit consumption over the past 30 days and auto top-up status. |

The data refreshes when you reload the page or select **Refresh**. Use the provider filter on the **Logs** tab to narrow individual message rows.

## Disconnect

Removing the API key disconnects the integration. Spotzee stops calling Sendmux and the Tool surface returns to the setup screen.

<Steps>
<Step title="Open the Email Proxy Tool">
Open **Tools** and pick **Email Proxy (Sendmux.ai)**.
</Step>

<Step title="Disconnect">
Use the disconnect action on the Overview tab. Confirm at the prompt.
</Step>
</Steps>

Disconnecting removes the saved API key from this Spotzee project. Your Sendmux account and providers remain available in Sendmux. Reconnect by entering a key on the setup screen.

## Rotating the API key

Two-step swap, like any credential rotation:

<Steps>
<Step title="Issue a new Sendmux API key">
On the Sendmux dashboard, generate a new `smx_root_` key.
</Step>

<Step title="Reconnect Spotzee">
In the Email Proxy Tool, disconnect the old key, then enter the new key on the setup screen. Spotzee validates it before loading your account data.
</Step>

<Step title="Revoke the old key">
On Sendmux, revoke the old key once Spotzee is using the new one.
</Step>
</Steps>
