The **Logs** tab inside the Spotzee Email Proxy Tool lists messages from your Sendmux account. Use it to check when a message was sent, which provider handled it, and its current status.

<Info>
Spotzee requests logs from your connected Sendmux account when you load or refresh this tab. The displayed fields and filters are those supported by the Spotzee view. The integration must be connected (see [Sendmux integration](/guides/tools/sendmux/overview)).
</Info>

## What you see

Each row in the logs view shows:

- **Time** and sender address.
- **Recipient** and subject, when available.
- **Status** (`pending`, `sent`, `failed`, or `rejected`).
- **Provider** and number of attempts.

The table shows one page at a time. Use **Next** and **Previous** to move between pages; changing filters starts again from the first page.

## Filter the list

The Logs tab supports these filters:

| Filter | What it does |
|---|---|
| **Status** | Select `pending`, `sent`, `failed`, or `rejected` |
| **Provider** | Scope to a single Sendmux provider |
| **Search** | Send search text to Sendmux to narrow the list |

You can combine the filters. Select **Refresh** to load the current page again.

## Check a status reason

When Sendmux supplies a status reason, hover over or focus the status badge to read it. Open the Sendmux dashboard for more detailed investigation.

## Common debugging patterns

A few flows that come up often:

- **A specific recipient isn't getting email.** Enter the address in **Search** and check the returned statuses and reasons.
- **A provider is failing more than usual.** Filter by provider and select **Failed** or **Rejected** to inspect its recent rows.
- **Check a single send.** Enter an identifying term in **Search**, then use the Sendmux dashboard if you need the full delivery record.
