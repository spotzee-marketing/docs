## A resource stays Pending

**Pending** means its first check has not completed. A newly added resource waits for its daily or weekly schedule unless you choose **Check now** from its row menu. After queuing a manual check, select **Refresh** to load the latest status. If checks remain pending, check the organisation's credit balance under **Billing** and contact support with the resource and last-check time.

## A resource is Disabled

**Disabled** means checks are paused for that resource. In its row menu, choose **Enable** to resume. The **Actions** menu also has **Enable all** for the whole IP or domain list. If the resource was disabled because credits ran out, restore the balance before checking again.

## An alert did not arrive

Confirm the latest check found a listing. Then review notification emails for the resource's group and the default notification emails in **Settings**. A group without recipients falls back to the default list. Check spam or quarantine folders, and allow for the hourly digest run. If no recipient list is configured, the result still appears in the Tool but no email is sent.

## CSV import rejects rows

The import reports accepted and rejected counts. Check rejected rows for missing or invalid `ip_address` or `domain` values, duplicate resources, or invalid group names. A valid new group name is created during import. Correct rejected rows and import them again.

## Check results look stale

Confirm the resource is enabled and its group uses the expected daily or weekly schedule. Choose **Check now** on one resource or **Actions** → **Check all** for the whole resource type, then select **Refresh** after the queued checks complete.
