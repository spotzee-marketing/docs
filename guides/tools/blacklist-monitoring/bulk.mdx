---

The **IPs** and **Domains** tabs each have an **Actions** menu. Its bulk actions apply to all resources of that type in the project. Searching the visible table does not narrow a bulk action.

## Import a CSV

<Steps>
  <Step title="Open the resource tab">
    Open **Tools** → **Blacklist Monitoring** → **IPs** or **Domains**.
  </Step>
  <Step title="Download a template">
    Choose **Actions** → **Import IPs** or **Import domains**, then select **Download template** in the import drawer.
  </Step>
  <Step title="Prepare and upload the file">
    Use the `ip_address` column for IPs or `domain` for domains. The optional `group_name` column assigns a resource to a group. A valid group name that does not exist is created with default settings.
  </Step>
  <Step title="Review the result">
    The import reports accepted and rejected row counts. Correct rejected rows and import them again if needed. New resources await their first check.
  </Step>
</Steps>

## Export a CSV

On the **IPs** or **Domains** tab, choose **Actions** → **Export IPs** or **Export domains**. The downloaded file contains all resources of that type in the project, including ones hidden by the current search text.

## Check or pause all resources

Choose **Actions** → **Check all** to queue checks for all checkable resources of that type. Choose **Disable all** to pause checks, or **Enable all** to resume them. These actions do not use row selection.

For one resource, use its row menu to choose **Check now**, **Enable** when disabled, **Change group**, or **Delete**.

## Delete all resources

Choose **Actions** → **Delete all**, then review the confirmation. This removes all resources of that type from the project, including resources hidden by search text. To remove only one resource, use its row menu.
