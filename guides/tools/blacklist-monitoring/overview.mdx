Blacklist Monitoring checks the IPs and domains you add against email blacklists. Set a daily or weekly schedule for each group, review results in the Tool, and receive digests for blacklisted check results.

<Info>
Blacklist Monitoring lives under **Tools** in the project sidebar and uses credits from your organisation's balance. The tool is read-and-write: you add resources, run checks, and configure groups; Spotzee handles the actual checking and alerting.
</Info>

## Why monitor blacklists

Email deliverability depends in part on sender reputation. A blacklist listing can affect delivery, so check which list reported it and investigate the cause before requesting removal.

The integration:

- **Watches IPs** (IPv4) against major RBLs.
- **Watches domains** against domain-based blacklists.
- **Schedules checks** on each resource by group (daily or weekly).
- **Sends digest emails** on the hourly dispatch for blacklisted check results.
- **Shows a 30-day history chart** so you can review listing patterns. Stored check records have a separate retention period.

## Open the Tool

<Steps>
<Step title="Open Tools">
Inside the project, open **Tools** from the sidebar.
</Step>

<Step title="Pick Blacklist Monitoring">
Choose **Blacklist Monitoring**. You'll land on the **Overview** tab if monitoring is already enabled, or a setup screen if it isn't.
</Step>
</Steps>

## The Overview tab

The Overview is your at-a-glance health view. Four statistics sit at the top:

| Stat | What it carries |
|---|---|
| **Total IPs** | The number of IPs you're monitoring |
| **Total domains** | The number of domains you're monitoring |
| **Clean** | How many resources have a clean status |
| **Blacklisted** | How many resources have a blacklisted status |

A 30-day history chart sits below the stats showing listing counts over time. A spike shows more resources listed on that day. Open the affected resources and check their latest status before deciding whether a listing has cleared.

## The four tabs

The Tool has four tabs:

| Tab | What's there |
|---|---|
| **Overview** | Stats cards plus the 30-day history chart |
| **IPs** | The list of monitored IPs, their statuses, and per-IP actions |
| **Domains** | The list of monitored domains, their statuses, and per-domain actions |
| **Settings** | RBL type selection, default notifications, group management |

For each, see the dedicated guide:

- [Manage monitored domains](/guides/tools/blacklist-monitoring/domains).
- [Use groups](/guides/tools/blacklist-monitoring/groups).
- [Configure settings](/guides/tools/blacklist-monitoring/setup).

## Credit usage

Blacklist checks consume platform credits from your organisation's balance. Keep an eye on your balance under **Billing**; monitoring pauses when credits run out.

For more on credits, see [Billing and credits](/guides/billing-and-credits).
