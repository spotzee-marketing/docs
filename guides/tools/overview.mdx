Spotzee offers one-off utilities, Extended API endpoints, and tools inside the project workspace. Availability and billing vary by tool; follow each guide for its supported surface and current usage details.

<Info>
**Choose the supported surface.** Some utilities have a one-off web form at [spotzee.com/tools](https://spotzee.com/tools/), some have an Extended API endpoint, and Blacklist Monitoring and Email Proxy live in the project workspace. Check the linked guide and [pricing page](https://spotzee.com/pricing/) before using a tool.
</Info>

<Info>
Use the tool when you need a single answer fast. Read the guide when you need to know what the answer means, what to do about it, and where it fits in the broader workflow.
</Info>
