Use sentiment analysis to inspect which words contribute positive or negative scores in a piece of text. Review the words in context before changing your copy. A score does not predict engagement, spam filtering or a reader's reaction.

<Info>
Open the [sentiment analysis tool](https://spotzee.com/tools/sentiment-analysis/). Extended API calls use your Spotzee credit balance; see [pricing](https://spotzee.com/pricing/) for current rates.
</Info>

## Review the result

<Steps>
  <Step title="Submit the text">
    Paste the text into the web form or submit the `text` field to the Extended API sentiment endpoint.
  </Step>
  <Step title="Compare total and per-token scores">
    `data.score` is the total sentiment score. Positive and negative values indicate the direction of the matched signals. `data.comparative` divides that score by the token count so length is visible in the comparison.
  </Step>
  <Step title="Inspect the contributing words">
    Read `data.calculation`, `data.positive` and `data.negative` to see which words contributed. `data.tokens` includes all analysed tokens; `data.words` contains the sentiment-bearing words.
  </Step>
</Steps>

A zero score can mean no recognised signals or positive and negative contributions that cancel. It does not prove the text has no emotion. Sarcasm, specialised language and context need human review.

The current endpoint uses its default language analysis even if a supported `language` value is supplied. Do not interpret that parameter as confirmation of language-specific scoring.
