Use the subject line suggester to generate variations of a draft. The service asks for a specified number of alternatives and returns a `subject_line` array. Review every suggestion before using it; generated text is not a deliverability or performance guarantee.

<Info>
Try a draft at [spotzee.com/tools/email-subject-suggest](https://spotzee.com/tools/email-subject-suggest).
</Info>

## Generate alternatives

<Steps>
  <Step title="Enter your draft">
    Provide the subject line you want to vary.
  </Step>
  <Step title="Choose a count">
    Request 1–10 suggestions through the documented API field. If you omit `count`, the controller defaults to 15.
  </Step>
  <Step title="Review the results">
    Read the returned `subject_line` array. The generation instructions ask for lines of no more than 80 characters, at most one emoji, and avoidance of listed spam words. Check the actual output, because generated suggestions can miss those instructions.
  </Step>
  <Step title="Choose and test">
    Edit for your brand voice and confirm any `[FNAME]` token matches your sending platform. Use the [subject line scorer](/guides/tools/content-analysis/email-subject-score) for a separate text-signal review.
  </Step>
</Steps>

The route schema documents `count` as 1–10; the controller has a wider 1–15 limit. Stay within 1–10 for API requests. Suggestions are generated from your input; they are not automatically scored, sent, or tested with recipients.
