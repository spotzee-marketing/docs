The URL verifier sends a request to a web address and reports `success` when the response status is successful, or `fail` otherwise. It checks reachability from the test service at that moment. It does not inspect page content or determine whether a URL is safe.

<Info>
Use the [web tool](https://spotzee.com/tools/url-verifier/) for one link. Extended API calls use your Spotzee credit balance; see [pricing](https://spotzee.com/pricing/) for current rates.
</Info>

## Check a link

<Steps>
  <Step title="Enter the URL">
    Enter an HTTPS URL. If you omit the scheme, the tool adds `https://` before sending the request.
  </Step>
  <Step title="Read the result">
    A `success` means the destination returned a successful response. A `fail` can mean a non-success HTTP status or a connection problem. Check the link in a browser when the result differs from what you expect.
  </Step>
  <Step title="Check the recipient journey">
    For a campaign link, open it in the same context your recipient will use. Confirm the page content and any required sign-in or redirect behaviour separately.
  </Step>
</Steps>

The request follows redirects. The result does not distinguish a direct response from a successful redirect destination.
