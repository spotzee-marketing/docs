---
title: "Malicious URL lookup"
description: "Availability and limitations of the malicious URL lookup."
keywords: ["malicious URL lookup", "URL safety", "phishing check"]
---

The malicious URL lookup is unavailable for threat screening. It returns a `listed: false` result without checking threat sources. **Do not treat this result as evidence that a URL is safe.**

If you are reviewing a campaign link, check it with a trusted threat-screening service before sending. The [URL verifier](/guides/tools/blacklist-security/url-verifier) can tell you whether a URL responds, but reachability is not a safety verdict.
