---
title: "SMTP server test"
description: "Availability and limitations of the SMTP server test."
keywords: ["SMTP server test", "SMTP connectivity", "email server test"]
---

The SMTP server test is unavailable for connectivity diagnosis. Its result does not establish that the hostname is reachable, that the server speaks SMTP, or that it supports STARTTLS. Do not use a successful result to approve a server configuration or troubleshoot delivery.

To check whether your sending configuration works, use the [SMTP email test](/guides/tools/smtp-testing/smtp-email-test) with a test account and a recipient you control. That test submits a message through the server you specify. Acceptance by the server does not confirm arrival in the recipient's inbox.
