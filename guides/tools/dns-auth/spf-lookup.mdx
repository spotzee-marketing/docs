Use the SPF lookup to find the `v=spf1` TXT record published for a domain. The result contains `exists` and, when a record is found, a `spfRecord` array with the matching TXT values.

<Info>
Enter a domain at [spotzee.com/tools/spf-lookup](https://spotzee.com/tools/spf-lookup/).
</Info>

## Check a domain

<Steps>
  <Step title="Enter the domain">
    Use the domain whose SPF record you want to inspect.
  </Step>
  <Step title="Read the returned records">
    If `exists` is `true`, inspect every value in `spfRecord`. If it is `false`, the lookup found no matching record. A DNS query failure can also return `exists: false` with an `error` message; check that message before changing DNS.
  </Step>
  <Step title="Evaluate the record separately">
    Review mechanisms such as `include:`, `a`, `mx`, and `redirect:` against your authorised senders. The lookup returns raw records; it does not parse mechanisms, count DNS lookups, or run SPF against a message.
  </Step>
</Steps>

Publishing more than one SPF record can make SPF evaluation fail. Check the returned array before adding another record. To inspect broader domain authentication signals, see the [email health check](/guides/tools/email-validation/email-health-check).

The same lookup is available through `POST /generic/email/spf-lookup` in the Spotzee Extended API. API calls use your credit balance; see [pricing](https://spotzee.com/pricing/) for the current rate.
